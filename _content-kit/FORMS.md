# Bian Lab 内容更新表

这个文件夹是站点的内部内容工具包，不参与页面展示。以后直接对我说“加新成员”“换某某的照片”“加一条 News”“Gallery 加照片”，我会把对应的表发给你。你只需要填已知项，不确定的写“待定”，我会追问或代拟英文。

## 通用约定

- **不改整体布局**：沿用现有 Bootstrap 栅格、导航、页脚和卡片样式。
- **照片只做非破坏处理**：旋转、按比例裁切、缩放、压缩、去除 EXIF/GPS；不磨皮、不调色、不修人脸、不生成内容。原图默认保留；只有你明确说“原图不要了”才覆盖。
- **科学图和艺术图默认不裁切**：只缩放到合适尺寸，避免裁掉坐标轴、标注、比例尺或画面主体。
- **上传前先预览**：我先给你看页面截图/裁切预览和 `git diff` 摘要，你确认后才 commit + push。
- **公开信息确认**：姓名、邮箱、照片、个人主页默认按你提供的内容公开；不想公开的项写“不公开”。
- **文件命名**：成员用 `firstlast.jpg`；新闻用 `YYYYMMDD_slug.jpg`；相册用 `YYYYMMDD_slug.jpg`。不要用中文、空格或 `#`。

## 照片规格速查

| 用途 | 比例 | 建议尺寸 | 处理方式 |
| --- | --- | --- | --- |
| 成员卡片 / 详情页 | 3:4 竖图 | 1200×1600 | 可裁切，脸部偏上 |
| News 配图 | 4:3 横图 | 1600×1200 | 可裁切 |
| Gallery Life | 4:3 横图 | 1600×1200 | 可裁切 |
| Gallery Science / Art | 原始比例 | 长边 ≤1600 | 不裁切 |
| 首页/栏目头图 | 16:9 | 2400×1350 | 可裁切 |
| Publication 图 | 原始比例 | 宽 ≤1200 | 不裁切 |

处理命令（内部使用）：

```bash
python _content-kit/prepare_image.py 原图.jpg --preset member --output images/team/firstlast.jpg
python _content-kit/prepare_image.py 原图.jpg --preset news --output images/news/YYYYMMDD/slug.jpg
python _content-kit/prepare_image.py 原图.png --preset gallery-figure --output images/gallery/science/slug.png
```

如果输出文件已存在，工具默认拒绝覆盖；加 `--force` 会先在同目录生成带时间戳的 `.bak` 备份，再写新文件。原图永远不会被修改。

## 上传前检查

我会运行：

```bash
python _content-kit/check_site.py
```

它会检查：

- 本地链接和图片是否存在；
- 每页是否有 viewport、description、canonical；
- 是否有重复 `id`；
- 是否有 `target="_blank"` 但缺少 `rel="noopener"`；
- 被引用的大图（超过 2 MB）列表。

有 error 时不上传；warning（比如空的装饰性 alt）会逐项判断。
